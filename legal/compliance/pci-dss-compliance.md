# Payment Security and PCI DSS Status

**Document status: internal compliance-scope draft; not an attestation or certification statement.**

This repository contains payment-provider integration code and payment-related configuration. The repository alone does not establish NIDAW's PCI DSS scope, compliance level, annual transaction volume, completion of a Qualified Security Assessor audit, or possession of an Attestation of Compliance.

Before this document is used externally, the legal/compliance owner must determine:

- whether NIDAW stores, processes or transmits cardholder data, or delegates all such handling to payment providers;
- the applicable PCI DSS scope and validation method;
- which payment providers and merchant/acquirer arrangements are actually contracted and active;
- which systems, personnel and third parties are in scope;
- the current assessment status and supporting evidence, if any;
- approved incident notification and evidence-retention obligations.

Do not claim PCI DSS certification, a compliance level, audited status or specific technical controls based only on this repository. Payment security controls must be verified against deployed systems and current provider contracts.
